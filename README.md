# RIFT FIGHTERS V34

Repositório do jogo RIFT FIGHTERS V34 para publicação pelo GitHub Pages.

Os arquivos do jogo são copiados automaticamente do projeto original `Vlzinn15x/Rift_Fighters_Novo` (pasta `public`) pelo fluxo de publicação do repositório.

Depois que o fluxo terminar, em **Settings > Pages**, configure **Deploy from a branch**, branch `main`, pasta `/(root)` para jogar em `https://vlzinn15x.github.io/Rift/`.

Modos solo e treinamento não precisam de servidor. Salas online precisam de backend separado.
